### Resumo sobre SQL Procedural Language

#### Origem
SQL Procedural Language (PL/SQL) é uma extensão da linguagem SQL desenvolvida pela Oracle Corporation no final dos anos 1980. A ideia era adicionar capacidades procedurais à SQL, permitindo a criação de blocos de código que poderiam ser executados como unidades, facilitando a programação de lógica complexa diretamente no banco de dados.

#### Conceitos
SQL Procedural Language combina a simplicidade da SQL com a robustez das linguagens de programação procedurais. Os principais conceitos incluem:

1. **Blocos de Código**: Estruturas que agrupam declarações, comandos e exceções.
2. **Variáveis e Tipos de Dados**: Permitem armazenar e manipular dados temporários.
3. **Controle de Fluxo**: Estruturas como loops, condicionais e instruções de controle.
4. **Procedures e Functions**: Subprogramas que encapsulam lógica reutilizável.
5. **Triggers**: Blocos de código que são executados automaticamente em resposta a eventos no banco de dados.
6. **Pacotes**: Coleções de procedures, functions, variáveis e outros elementos que são agrupados logicamente.

#### Tipos e Classificações

1. **Blocos Anônimos**
   - **Características**: Não têm nome e não são armazenados no banco de dados. São usados para tarefas ad-hoc.
   - **Exemplo**:
     ```sql
     DECLARE
       v_variable NUMBER;
     BEGIN
       v_variable := 10;
       DBMS_OUTPUT.PUT_LINE('Value: ' || v_variable);
     END;
     ```

2. **Procedures**
   - **Características**: Subprogramas nomeados que podem aceitar parâmetros e não retornam valores diretamente.
   - **Exemplo**:
     ```sql
     CREATE OR REPLACE PROCEDURE update_salary(emp_id NUMBER, new_salary NUMBER) IS
     BEGIN
       UPDATE employees SET salary = new_salary WHERE employee_id = emp_id;
     END;
     ```

3. **Functions**
   - **Características**: Subprogramas nomeados que podem aceitar parâmetros e retornam um valor.
   - **Exemplo**:
     ```sql
     CREATE OR REPLACE FUNCTION get_employee_name(emp_id NUMBER) RETURN VARCHAR2 IS
       v_name VARCHAR2(100);
     BEGIN
       SELECT name INTO v_name FROM employees WHERE employee_id = emp_id;
       RETURN v_name;
     END;
     ```

4. **Triggers**
   - **Características**: Blocos de código que são executados automaticamente em resposta a eventos como INSERT, UPDATE ou DELETE.
   - **Tipos de Triggers**:
     - **Row-level Triggers**: Executados para cada linha afetada.
     - **Statement-level Triggers**: Executados uma vez por operação.
   - **Exemplo**:
     ```sql
     CREATE OR REPLACE TRIGGER trg_before_insert
     BEFORE INSERT ON employees
     FOR EACH ROW
     BEGIN
       :NEW.created_at := SYSDATE;
     END;
     ```

5. **Pacotes**
   - **Características**: Coleções de procedures, functions, variáveis e outros elementos agrupados logicamente.
   - **Componentes**:
     - **Specification**: Declarações públicas.
     - **Body**: Implementações privadas.
   - **Exemplo**:
     ```sql
     CREATE OR REPLACE PACKAGE emp_pkg IS
       PROCEDURE update_salary(emp_id NUMBER, new_salary NUMBER);
       FUNCTION get_employee_name(emp_id NUMBER) RETURN VARCHAR2;
     END emp_pkg;
     
     CREATE OR REPLACE PACKAGE BODY emp_pkg IS
       PROCEDURE update_salary(emp_id NUMBER, new_salary NUMBER) IS
       BEGIN
         UPDATE employees SET salary = new_salary WHERE employee_id = emp_id;
       END update_salary;
       
       FUNCTION get_employee_name(emp_id NUMBER) RETURN VARCHAR2 IS
         v_name VARCHAR2(100);
       BEGIN
         SELECT name INTO v_name FROM employees WHERE employee_id = emp_id;
         RETURN v_name;
       END get_employee_name;
     END emp_pkg;
     ```

   - **Características**: Permitem a manipulação de conjuntos de resultados linha a linha.
