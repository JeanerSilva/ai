### Resumo sobre DNS em Rede Microsoft Windows Server

#### Origem
O DNS (Domain Name System) é um sistema essencial para a funcionalidade da internet e redes corporativas, incluindo aquelas baseadas no Microsoft Windows Server. Ele foi desenvolvido na década de 1980 para substituir o sistema anterior de arquivos HOSTS.TXT, que não era escalável para o crescimento da internet. O DNS permite a tradução de nomes de domínio legíveis por humanos (como www.exemplo.com) em endereços IP numéricos (como 192.0.2.1), que são utilizados pelos computadores para se comunicarem entre si.

#### Conceitos
- **Nome de Domínio**: Um nome legível por humanos que é mapeado para um endereço IP.
- **Endereço IP**: Um identificador numérico único para um dispositivo em uma rede.
- **Zona**: Uma porção do espaço de nomes do DNS que é gerenciada por um servidor DNS específico.
- **Registro DNS**: Entradas em uma zona DNS que mapeiam nomes de domínio para endereços IP ou outras informações.
- **Servidor DNS**: Um servidor que responde a consultas de DNS, fornecendo a tradução de nomes de domínio para endereços IP.
- **Resolução de Nome**: O processo de tradução de um nome de domínio em um endereço IP.

#### Tipos e Classificações de DNS em Rede Microsoft Windows Server

1. **Tipos de Servidores DNS**
   - **Servidor DNS Primário**: Armazena os arquivos de zona originais e é a fonte autoritativa para a zona.
   - **Servidor DNS Secundário**: Obtém uma cópia dos arquivos de zona do servidor primário e fornece redundância.
   - **Servidor de Cache-Only**: Não contém zonas autoritativas, apenas armazena em cache as respostas de consultas DNS para melhorar a eficiência.
   - **Servidor de Encaminhamento (Forwarder)**: Encaminha consultas DNS para servidores DNS externos, geralmente para resolver nomes fora da rede local.

2. **Tipos de Zonas DNS**
   - **Zona Primária**: Contém os registros DNS originais e é editável diretamente.
   - **Zona Secundária**: Uma cópia somente leitura da zona primária, usada para redundância e balanceamento de carga.
   - **Zona Stub**: Contém apenas registros necessários para localizar servidores DNS autoritativos para uma zona.
   - **Zona Integrada ao Active Directory**: Armazena os dados da zona no Active Directory, permitindo replicação automática entre controladores de domínio.

3. **Tipos de Registros DNS**
   - **A (Address)**: Mapeia um nome de domínio para um endereço IPv4.
   - **AAAA (IPv6 Address)**: Mapeia um nome de domínio para um endereço IPv6.
   - **CNAME (Canonical Name)**: Cria um alias para outro nome de domínio.
   - **MX (Mail Exchange)**: Especifica servidores de e-mail para o domínio.
   - **PTR (Pointer)**: Mapeia um endereço IP para um nome de domínio (usado em consultas reversas).
   - **NS (Name Server)**: Especifica servidores DNS autoritativos para a zona.
   - **SOA (Start of Authority)**: Contém informações sobre a zona e o servidor DNS primário.
   - **SRV (Service)**: Especifica serviços disponíveis em um domínio.
   - **TXT (Text)**: Armazena informações textuais associadas a um domínio, frequentemente usado para verificação de domínio e políticas de e-mail.

4. **Tipos de Consultas DNS**
   - **Consulta Recursiva**: O servidor DNS assume a responsabilidade de resolver a consulta completamente, retornando uma resposta final ao cliente.
   - **Consulta Iterativa**: O servidor DNS responde com a melhor informação que possui, geralmente um redirecionamento para outro servidor DNS mais próximo da resposta final.
   - **Consulta Inversa**: Traduz um endereço IP em um nome de domínio, utilizando registros PTR.

### Características dos Tipos de Servidores DNS

- **Servidor DNS Primário**:
  - Armazena os dados originais da zona.
  - Permite edição direta dos registros DNS.
  - É a fonte autoritativa para a zona.

- **Servidor DNS Secundário**:
  - Mantém uma cópia somente leitura da zona primária.
  - Sincroniza periodicamente com o servidor primário.
  - Fornece redundância e balanceamento de carga.

- **Servidor de Cache-Only**:
  - Não contém zonas autoritativas.
  - Armazena em cache as respostas de consultas DNS.
  - Melhora a eficiência e reduz a carga em servidores autoritativos.

- **Servidor de Encaminhamento (Forwarder)**:
  - Encaminha consultas DNS para servidores externos.
