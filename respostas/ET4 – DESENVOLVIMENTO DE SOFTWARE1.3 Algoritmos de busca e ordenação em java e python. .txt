### Algoritmos de Busca

#### Busca Linear (Linear Search)
- **Conceito**: Percorre a lista do início ao fim, comparando cada elemento com o valor buscado.
- **Complexidade**: O(n), onde n é o número de elementos na lista.
- **Implementação**:
  - **Java**:
    ```java
    public int linearSearch(int[] arr, int key) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == key) {
                return i;
            }
        }
        return -1;
    }
    ```
  - **Python**:
    ```python
    def linear_search(arr, key):
        for i in range(len(arr)):
            if arr[i] == key:
                return i
        return -1
    ```

#### Busca Binária (Binary Search)
- **Conceito**: Requer uma lista ordenada. Divide a lista ao meio e compara o elemento do meio com o valor buscado, descartando metade da lista a cada iteração.
- **Complexidade**: O(log n).
- **Implementação**:
  - **Java**:
    ```java
    public int binarySearch(int[] arr, int key) {
        int left = 0, right = arr.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (arr[mid] == key) return mid;
            if (arr[mid] < key) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
    ```
  - **Python**:
    ```python
    def binary_search(arr, key):
        left, right = 0, len(arr) - 1
        while left <= right:
            mid = (left + right) // 2
            if arr[mid] == key:
                return mid
            elif arr[mid] < key:
                left = mid + 1
            else:
                right = mid - 1
        return -1
    ```

### Algoritmos de Ordenação

#### Bubble Sort
- **Conceito**: Repetidamente percorre a lista, comparando e trocando elementos adjacentes que estão fora de ordem.
- **Complexidade**: O(n^2).
- **Implementação**:
  - **Java**:
    ```java
    public void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n-1; i++) {
            for (int j = 0; j < n-i-1; j++) {
                if (arr[j] > arr[j+1]) {
                    int temp = arr[j];
                    arr[j] = arr[j+1];
                    arr[j+1] = temp;
                }
            }
        }
    }
    ```
  - **Python**:
    ```python
    def bubble_sort(arr):
        n = len(arr)
        for i in range(n):
            for j in range(0, n-i-1):
                if arr[j] > arr[j+1]:
                    arr[j], arr[j+1] = arr[j+1], arr[j]
    ```

#### Selection Sort
- **Conceito**: Encontra o menor elemento da lista e o coloca na posição inicial, repetindo o processo para os elementos restantes.
- **Complexidade**: O(n^2).
- **Implementação**:
  - **Java**:
    ```java
    public void selectionSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n-1; i++) {
            int min_idx = i;
            for (int j = i+1; j < n; j++) {
                if (arr[j] < arr[min_idx]) {
                    min_idx = j;
                }
            }
            int temp = arr[min_idx];
            arr[min_idx] = arr[i];
            arr[i] = temp;
        }
    }
    ```
  - **Python**:
    ```python
    def selection_sort(arr):
        n = len(arr)
        for i in range(n):
            min_idx = i
            for j in range(i+1, n):
                if arr[j] < arr[min_idx]:
                    min_idx = j
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    ```

#### Insertion Sort
- **Conceito**: Constrói a lista ordenada um elemento de cada vez, inserindo cada novo elemento na posição correta.
- **Complexidade**: O(n^2).
