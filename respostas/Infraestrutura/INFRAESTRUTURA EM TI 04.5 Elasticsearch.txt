INFRAESTRUTURA EM TI:: 04.5 Elasticsearch
 -
Claro! Elasticsearch é uma ferramenta poderosa para busca e análise de dados em tempo real. Para entender os conceitos mais importantes que te ajudarão a compreender a maior parte do funcionamento do Elasticsearch, vamos focar nos princípios de Pareto (80/20). Aqui estão os 20% mais importantes aprendizados:

1. **Conceito de Índices e Documentos**:
   - **Índices**: São coleções de documentos que compartilham características semelhantes. Pense neles como bancos de dados em um sistema de banco de dados relacional.
   - **Documentos**: São as unidades básicas de informação que podem ser indexadas. Cada documento é um conjunto de campos (como uma linha em uma tabela de banco de dados).

2. **Estrutura de Dados JSON**:
   - Elasticsearch armazena dados em formato JSON, o que facilita a indexação e a busca de dados complexos e aninhados.

3. **Cluster, Nodes e Shards**:
   - **Cluster**: Um conjunto de um ou mais nós (nodes) que juntos armazenam todos os dados e fornecem capacidades de busca em todo o cluster.
   - **Node**: Uma única instância do Elasticsearch. Um cluster pode ter muitos nós.
   - **Shards**: Cada índice pode ser dividido em múltiplos shards, que são unidades menores de um índice. Isso permite a distribuição e a paralelização de operações.

4. **Replicação e Tolerância a Falhas**:
   - **Replicas**: Cada shard pode ter réplicas para garantir alta disponibilidade e tolerância a falhas. Se um nó falhar, as réplicas garantem que os dados ainda estejam acessíveis.

5. **Análise e Tokenização**:
   - **Analisadores**: Processam o texto de entrada e o transformam em tokens (palavras ou termos) que podem ser indexados. Analisadores podem incluir filtros de caracteres, tokenizadores e filtros de tokens.

6. **Consultas (Queries)**:
   - **Query DSL (Domain Specific Language)**: Uma linguagem específica de domínio usada para construir consultas complexas. Inclui várias formas de consultas como `match`, `term`, `range`, `bool`, etc.

7. **Agregações**:
   - Permitem a análise de dados e a extração de insights. Agregações podem ser usadas para calcular estatísticas, histogramas, e outras métricas sobre os dados indexados.

8. **Mappings e Tipos de Dados**:
   - **Mappings**: Definem como os documentos e seus campos são armazenados e indexados. Incluem tipos de dados como `text`, `keyword`, `date`, `integer`, etc.

9. **Ingest Nodes e Pipelines**:
   - **Ingest Nodes**: Permitem o pré-processamento de documentos antes de serem indexados. Pipelines de ingestão podem incluir processadores para modificar, enriquecer ou transformar dados.

10. **Escalabilidade e Desempenho**:
    - Elasticsearch é projetado para ser escalável horizontalmente. Adicionar mais nós ao cluster pode melhorar o desempenho e a capacidade de armazenamento.

11. **RESTful API**:
    - Elasticsearch oferece uma API RESTful que permite interagir com o cluster usando HTTP. Isso facilita a integração com outras aplicações e serviços.

12. **Full-Text Search**:
    - Elasticsearch é otimizado para busca de texto completo, permitindo buscas rápidas e relevantes em grandes volumes de texto.

13. **Facetas e Filtros**:
    - **Facetas**: Permitem a navegação e a filtragem de resultados de busca com base em categorias ou atributos.
    - **Filtros**: Permitem restringir os resultados de busca com base em critérios específicos sem afetar a pontuação dos resultados.

14. **Monitoramento e Gerenciamento**:
    - Ferramentas como Kibana podem ser usadas para monitorar e gerenciar clusters Elasticsearch, visualizar dados e criar dashboards interativos.

15. **Segurança**:
    - Elasticsearch oferece recursos de segurança como autenticação, autorização, criptografia de dados em trânsito e em repouso, e controle de acesso baseado em funções (RBAC).

16. **Atualizações e Deleções**:
    - **Atualizações**: Documentos podem ser atualizados parcialmente ou completamente.
    - **Deleções**: Documentos podem ser deletados, e Elasticsearch gerencia a remoção física dos dados de forma eficiente.

17. **Snapshot e Restore**:
    - Permite criar backups dos índices e restaurá-los quando necessário, garantindo a recuperação de dados em caso de falhas.

18. **Scriptings e Plugins**:
    - Elasticsearch suporta scripts para personalizar consultas e agregações. Plugins podem ser usados para estender funcionalidades.

19. **Reindexação**:
    - Permite copiar dados de um índice para outro, útil para mudanças de mapeamento ou otimizações.
