SEGURANÇA DA INFORMAÇÃO:: 04 Controles e testes de segurança para aplicações Web e Web Services. 
 -
### Origem e Conceitos

Os controles e testes de segurança para aplicações Web e Web Services surgiram da necessidade de proteger dados e garantir a integridade, confidencialidade e disponibilidade dos sistemas online. Com o aumento da dependência de aplicações web e serviços web, a segurança tornou-se uma prioridade para evitar ataques cibernéticos, fraudes e vazamentos de dados.

### Tipos e Classificações

#### 1. **Autenticação e Autorização**

**Conceito:** Garantir que apenas usuários autorizados possam acessar os recursos e funcionalidades da aplicação.

**Tipos:**
- **Autenticação de Usuário:** Verificação da identidade do usuário através de métodos como senhas, tokens, biometria, etc.
- **Autorização de Acesso:** Controle de permissões para determinar o que cada usuário pode fazer após ser autenticado.

**Características:**
- **Autenticação Multifator (MFA):** Combinação de dois ou mais métodos de autenticação.
- **OAuth:** Protocolo de autorização que permite acesso limitado a recursos do usuário sem expor credenciais.
- **JWT (JSON Web Tokens):** Tokens compactos e seguros para transmitir informações entre partes como um objeto JSON.

#### 2. **Validação de Entrada**

**Conceito:** Garantir que os dados fornecidos pelo usuário sejam válidos e seguros antes de serem processados pela aplicação.

**Tipos:**
- **Validação do Lado do Cliente:** Verificação de dados no navegador do usuário antes de enviar ao servidor.
- **Validação do Lado do Servidor:** Verificação de dados no servidor após serem recebidos do cliente.

**Características:**
- **Sanitização de Entrada:** Remoção de caracteres potencialmente perigosos.
- **Escapamento de Dados:** Transformação de dados para evitar execução de código malicioso.
- **Whitelist/Blacklist:** Listas de valores permitidos ou proibidos.

#### 3. **Criptografia**

**Conceito:** Proteção de dados através de técnicas de codificação para garantir que apenas partes autorizadas possam acessar a informação.

**Tipos:**
- **Criptografia Simétrica:** Utiliza a mesma chave para criptografar e descriptografar dados.
- **Criptografia Assimétrica:** Utiliza um par de chaves (pública e privada) para criptografar e descriptografar dados.
- **Hashing:** Transformação de dados em uma sequência fixa de caracteres, que não pode ser revertida.

**Características:**
- **TLS/SSL:** Protocolos para criptografar a comunicação entre cliente e servidor.
- **AES (Advanced Encryption Standard):** Algoritmo de criptografia simétrica amplamente utilizado.
- **RSA:** Algoritmo de criptografia assimétrica usado para proteger dados sensíveis.

#### 4. **Testes de Segurança**

**Conceito:** Avaliação sistemática das aplicações para identificar e corrigir vulnerabilidades de segurança.

**Tipos:**
- **Testes de Penetração (Pen Testing):** Simulação de ataques para identificar vulnerabilidades.
- **Análise de Código Estático (SAST):** Revisão do código-fonte para identificar vulnerabilidades sem executá-lo.
- **Análise de Código Dinâmico (DAST):** Testes de segurança em aplicações em execução para identificar vulnerabilidades.
- **Testes de Fuzzing:** Envio de dados aleatórios para a aplicação para identificar falhas e vulnerabilidades.

**Características:**
- **Automatizados vs. Manuais:** Testes podem ser realizados por ferramentas automatizadas ou por analistas de segurança.
- **Cobertura de Testes:** Abrangência dos testes em termos de funcionalidades e componentes da aplicação.
- **Relatórios de Vulnerabilidades:** Documentação das falhas encontradas e recomendações para correção.

### Conclusão

A segurança de aplicações Web e Web Services é um campo complexo e multifacetado, que envolve a implementação de diversos controles e a realização de testes rigorosos. A autenticação e autorização, a validação de entrada, a criptografia e os testes de segurança são componentes essenciais para proteger as aplicações contra ameaças cibernéticas. Cada tipo de controle e teste possui suas próprias características e métodos, que devem ser cuidadosamente escolhidos e implementados para garantir a segurança eficaz das aplicações.
