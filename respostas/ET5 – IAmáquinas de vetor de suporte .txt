### Máquinas de Vetor de Suporte (SVM)

#### Definição
- **Máquinas de Vetor de Suporte (SVM)** são um conjunto de métodos de aprendizado supervisionado usados para classificação, regressão e detecção de outliers.

#### Conceitos Principais
1. **Hiperplano**:
   - É uma linha (em 2D) ou um plano (em 3D) que separa os dados em diferentes classes.
   - O objetivo do SVM é encontrar o hiperplano que maximiza a margem entre as classes.

2. **Margem**:
   - A margem é a distância entre o hiperplano e os pontos de dados mais próximos de qualquer classe.
   - SVM busca maximizar essa margem para melhorar a generalização do modelo.

3. **Vetores de Suporte**:
   - São os pontos de dados que estão mais próximos do hiperplano e que definem a posição e orientação do hiperplano.
   - Esses pontos são críticos para a construção do modelo SVM.

4. **Kernel**:
   - Funções de kernel permitem que SVMs operem em um espaço de características de alta dimensão sem a necessidade de calcular as coordenadas dos dados nesse espaço.
   - Tipos comuns de kernels incluem:
     - **Linear**: usado quando os dados são linearmente separáveis.
     - **Polinomial**: usado para dados que não são linearmente separáveis.
     - **RBF (Radial Basis Function)**: usado para dados complexos e não linearmente separáveis.
     - **Sigmoide**: usado em redes neurais.

5. **Parâmetro C**:
   - Controla a penalidade de erros de classificação.
   - Um valor alto de C tenta classificar todos os pontos corretamente, enquanto um valor baixo de C permite mais erros, promovendo uma margem maior.

6. **Soft Margin vs. Hard Margin**:
   - **Hard Margin**: não permite erros de classificação, adequado para dados perfeitamente separáveis.
   - **Soft Margin**: permite alguns erros de classificação, adequado para dados não perfeitamente separáveis.

#### Aplicações
- **Classificação**: SVM é amplamente utilizado para problemas de classificação binária e multiclasse.
- **Regressão**: SVM pode ser adaptado para problemas de regressão (SVR - Support Vector Regression).
- **Detecção de Outliers**: SVM pode ser usado para identificar anomalias em conjuntos de dados.

#### Vantagens
- Eficaz em espaços de alta dimensão.
- Eficaz quando o número de dimensões é maior que o número de amostras.
- Usa um subconjunto de pontos de treinamento (vetores de suporte), tornando-o eficiente em termos de memória.

#### Desvantagens
- Não é adequado para conjuntos de dados muito grandes devido ao custo computacional.
- Desempenho pode ser afetado se o número de características for muito maior que o número de amostras.
- Escolha do kernel e ajuste dos parâmetros podem ser complexos.
