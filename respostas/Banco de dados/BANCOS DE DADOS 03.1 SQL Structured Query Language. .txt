BANCOS DE DADOS:: 03.1 SQL Structured Query Language. 
 -
**SQL (Structured Query Language)**

**Origem:**
SQL, ou Structured Query Language, é uma linguagem de programação padrão utilizada para gerenciar e manipular bancos de dados relacionais. Foi desenvolvida inicialmente na década de 1970 por Donald D. Chamberlin e Raymond F. Boyce nos laboratórios da IBM, como parte do projeto System R. A primeira versão comercial de SQL foi lançada pela Oracle em 1979. Desde então, SQL tornou-se o padrão de fato para interação com sistemas de gerenciamento de banco de dados (SGBDs) relacionais.

**Conceitos:**
SQL é usada para realizar várias operações em bancos de dados, incluindo a criação, leitura, atualização e exclusão de dados. Os principais conceitos de SQL incluem:

1. **DDL (Data Definition Language)**: Utilizada para definir e gerenciar estruturas de banco de dados, como tabelas e índices.
2. **DML (Data Manipulation Language)**: Utilizada para manipular dados dentro das estruturas de banco de dados.
3. **DCL (Data Control Language)**: Utilizada para controlar o acesso aos dados no banco de dados.
4. **TCL (Transaction Control Language)**: Utilizada para gerenciar transações no banco de dados.

**Tipos e Classificações:**

1. **DDL (Data Definition Language):**
   - **CREATE**: Cria novas tabelas, índices, vistas, etc.
     - Exemplo: `CREATE TABLE Employees (ID INT, Name VARCHAR(100));`
   - **ALTER**: Modifica a estrutura de uma tabela existente.
     - Exemplo: `ALTER TABLE Employees ADD COLUMN Age INT;`
   - **DROP**: Remove tabelas, índices, vistas, etc.
     - Exemplo: `DROP TABLE Employees;`
   - **TRUNCATE**: Remove todos os registros de uma tabela, mas mantém a estrutura.
     - Exemplo: `TRUNCATE TABLE Employees;`

2. **DML (Data Manipulation Language):**
   - **SELECT**: Recupera dados de uma ou mais tabelas.
     - Exemplo: `SELECT * FROM Employees;`
   - **INSERT**: Insere novos registros em uma tabela.
     - Exemplo: `INSERT INTO Employees (ID, Name) VALUES (1, 'John Doe');`
   - **UPDATE**: Atualiza dados existentes em uma tabela.
     - Exemplo: `UPDATE Employees SET Name = 'Jane Doe' WHERE ID = 1;`
   - **DELETE**: Remove registros de uma tabela.
     - Exemplo: `DELETE FROM Employees WHERE ID = 1;`

3. **DCL (Data Control Language):**
   - **GRANT**: Concede permissões a usuários.
     - Exemplo: `GRANT SELECT ON Employees TO User1;`
   - **REVOKE**: Revoga permissões de usuários.
     - Exemplo: `REVOKE SELECT ON Employees FROM User1;`

4. **TCL (Transaction Control Language):**
   - **COMMIT**: Confirma uma transação, tornando todas as alterações permanentes.
     - Exemplo: `COMMIT;`
   - **ROLLBACK**: Desfaz uma transação, revertendo todas as alterações feitas.
     - Exemplo: `ROLLBACK;`
   - **SAVEPOINT**: Define um ponto dentro de uma transação para que seja possível fazer um rollback parcial.
     - Exemplo: `SAVEPOINT Savepoint1;`
   - **SET TRANSACTION**: Define características de uma transação, como o nível de isolamento.
     - Exemplo: `SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;`

**Características dos Tipos:**

- **DDL**: Foca na estrutura do banco de dados. As operações DDL são geralmente auto-commit, o que significa que uma vez executadas, não podem ser revertidas.
- **DML**: Foca na manipulação dos dados dentro das estruturas definidas pelo DDL. As operações DML podem ser revertidas se não forem confirmadas com um COMMIT.
- **DCL**: Foca no controle de acesso aos dados. Permite definir quem pode fazer o quê dentro do banco de dados.
- **TCL**: Foca na gestão de transações, garantindo a integridade e consistência dos dados durante operações complexas.

SQL é uma linguagem poderosa e essencial para a gestão de bancos de dados relacionais, oferecendo uma ampla gama de comandos para atender às necessidades de definição, manipulação, controle e transação de dados.
