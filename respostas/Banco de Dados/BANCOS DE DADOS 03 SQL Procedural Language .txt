BANCOS DE DADOS:: 03 SQL Procedural Language 
 -
Claro! Vamos focar nos aspectos mais importantes das três principais linguagens procedurais SQL: PL/pgSQL (PostgreSQL), T-SQL (SQL Server) e PL/SQL (Oracle). Esses pontos são essenciais para você compreender a maior parte do que precisa saber sobre essas linguagens.

### 1. **PL/pgSQL (PostgreSQL)**

#### a. **Estrutura Básica**
   - **Declaração de Blocos**: PL/pgSQL usa blocos `BEGIN ... END` para agrupar instruções.
   - **Variáveis**: Declaração de variáveis usando `DECLARE`.

#### b. **Controle de Fluxo**
   - **Condicionais**: Uso de `IF ... THEN ... ELSE`.
   - **Loops**: `LOOP`, `WHILE`, `FOR`.

#### c. **Funções e Procedimentos**
   - **Funções**: Criar funções com `CREATE FUNCTION`.
   - **Procedimentos**: Uso de `CREATE PROCEDURE` para procedimentos armazenados.

#### d. **Tratamento de Exceções**
   - **EXCEPTION**: Blocos de tratamento de exceções para capturar e lidar com erros.

### 2. **T-SQL (SQL Server)**

#### a. **Estrutura Básica**
   - **Blocos BEGIN ... END**: Agrupamento de instruções.
   - **Variáveis**: Declaração com `DECLARE`.

#### b. **Controle de Fluxo**
   - **Condicionais**: Uso de `IF ... ELSE`.
   - **Loops**: `WHILE`.

#### c. **Funções e Procedimentos**
   - **Procedimentos Armazenados**: Criar com `CREATE PROCEDURE`.
   - **Funções Definidas pelo Usuário**: Uso de `CREATE FUNCTION`.

#### d. **Tratamento de Exceções**
   - **TRY ... CATCH**: Blocos para captura e tratamento de exceções.

### 3. **PL/SQL (Oracle)**

#### a. **Estrutura Básica**
   - **Blocos BEGIN ... END**: Estrutura de blocos.
   - **Variáveis**: Declaração com `DECLARE`.

#### b. **Controle de Fluxo**
   - **Condicionais**: Uso de `IF ... THEN ... ELSE`.
   - **Loops**: `LOOP`, `WHILE`, `FOR`.

#### c. **Funções e Procedimentos**
   - **Procedimentos**: Criar com `CREATE PROCEDURE`.
   - **Funções**: Uso de `CREATE FUNCTION`.

#### d. **Tratamento de Exceções**
   - **EXCEPTION**: Blocos para tratamento de exceções.

### Resumo dos 20% mais importantes:

1. **Estrutura de Blocos**: Entender como agrupar instruções em blocos `BEGIN ... END`.
2. **Declaração de Variáveis**: Saber como declarar e usar variáveis.
3. **Controle de Fluxo**: Uso de condicionais (`IF ... THEN ... ELSE`) e loops (`LOOP`, `WHILE`, `FOR`).
4. **Funções e Procedimentos**: Saber criar e usar funções e procedimentos armazenados.
5. **Tratamento de Exceções**: Capturar e tratar erros usando blocos de exceção (`EXCEPTION` ou `TRY ... CATCH`).

Compreender esses pontos-chave fornecerá uma base sólida para trabalhar com as linguagens procedurais SQL mais comuns e permitirá que você aborde a maioria das tarefas e problemas que encontrará.
