### 1. **Conceitos Básicos de Modelagem de Dados**
   - **Definição**: Modelagem de dados é o processo de criar uma estrutura de dados que representa as informações necessárias para um sistema.
   - **Objetivo**: Facilitar a compreensão, organização e manipulação dos dados.

### 2. **Tipos de Modelos de Dados**
   - **Modelo Conceitual**: Representa a visão de alto nível dos dados, focando em entidades e relacionamentos. Exemplo: Diagrama de Entidade-Relacionamento (ER).
   - **Modelo Lógico**: Detalha a estrutura dos dados sem considerar aspectos físicos. Exemplo: Tabelas, colunas, tipos de dados.
   - **Modelo Físico**: Descreve como os dados serão armazenados fisicamente no banco de dados. Exemplo: Índices, partições.

### 3. **Entidades e Relacionamentos**
   - **Entidades**: Objetos ou conceitos que armazenam dados. Exemplo: Cliente, Produto.
   - **Relacionamentos**: Conexões entre entidades. Exemplo: Um cliente pode fazer muitos pedidos.

### 4. **Atributos**
   - **Definição**: Características ou propriedades de uma entidade. Exemplo: Nome do Cliente, Preço do Produto.
   - **Tipos de Atributos**: Simples, composto, derivado, multivalorado.

### 5. **Chaves Primárias e Estrangeiras**
   - **Chave Primária (PK)**: Identificador único para uma entidade. Exemplo: ID do Cliente.
   - **Chave Estrangeira (FK)**: Campo que cria uma relação entre duas tabelas. Exemplo: ID do Cliente na tabela de Pedidos.

### 6. **Normalização**
   - **Objetivo**: Eliminar redundâncias e garantir a integridade dos dados.
   - **Formas Normais**: 1NF, 2NF, 3NF, BCNF, etc.

### 7. **Denormalização**
   - **Definição**: Processo de introduzir redundâncias para melhorar a performance de leitura.
   - **Quando Usar**: Em sistemas onde a leitura é mais frequente que a escrita.

### 8. **Diagramas de Entidade-Relacionamento (ER)**
   - **Componentes**: Entidades, relacionamentos, atributos.
   - **Notações**: Chen, Crow's Foot, UML.

### 9. **Cardinalidade**
   - **Definição**: Descreve o número de instâncias de uma entidade que podem estar associadas a uma instância de outra entidade.
   - **Tipos**: Um-para-um, um-para-muitos, muitos-para-muitos.

### 10. **Integridade Referencial**
   - **Definição**: Garantir que as relações entre tabelas permaneçam consistentes.
   - **Mecanismos**: Restrições de chave estrangeira, cascata de exclusão/atualização.

### 11. **Modelagem Dimensional**
   - **Definição**: Técnica usada em data warehouses para facilitar a consulta e análise de dados.
   - **Componentes**: Fatos e dimensões.

### 12. **Tabelas de Fatos e Dimensões**
   - **Tabela de Fatos**: Contém dados quantitativos para análise. Exemplo: Vendas.
   - **Tabela de Dimensões**: Contém dados descritivos. Exemplo: Data, Produto, Cliente.

### 13. **Esquemas Estrela e Floco de Neve**
   - **Esquema Estrela**: Tabelas de fatos ligadas diretamente a tabelas de dimensões.
   - **Esquema Floco de Neve**: Tabelas de dimensões normalizadas.

### 14. **Modelagem de Dados NoSQL**
   - **Tipos de Bancos NoSQL**: Documentos, chave-valor, colunar, grafos.
   - **Quando Usar**: Para grandes volumes de dados não estruturados ou semi-estruturados.

### 15. **Ferramentas de Modelagem de Dados**
   - **Exemplos**: ER/Studio, ERwin, MySQL Workbench, Microsoft Visio.
