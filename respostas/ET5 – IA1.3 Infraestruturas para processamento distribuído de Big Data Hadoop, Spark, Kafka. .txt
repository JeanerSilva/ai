### 1.3 Infraestruturas para Processamento Distribuído de Big Data

#### Hadoop
- **Conceito**: Framework de software de código aberto para armazenamento e processamento distribuído de grandes conjuntos de dados.
- **Componentes Principais**:
  - **HDFS (Hadoop Distributed File System)**: Sistema de arquivos distribuído que armazena dados em clusters.
  - **MapReduce**: Modelo de programação para processamento paralelo de grandes volumes de dados.
  - **YARN (Yet Another Resource Negotiator)**: Gerenciador de recursos do cluster que coordena as tarefas de processamento.
  - **Hadoop Common**: Conjunto de utilitários e bibliotecas comuns que suportam outros módulos Hadoop.

#### Spark
- **Conceito**: Motor de análise unificada para processamento de dados em grande escala, conhecido por sua velocidade e facilidade de uso.
- **Principais Características**:
  - **RDD (Resilient Distributed Dataset)**: Estrutura de dados fundamental do Spark que permite operações de transformação e ação.
  - **Spark SQL**: Módulo para trabalhar com dados estruturados usando SQL.
  - **Spark Streaming**: Processamento de dados em tempo real.
  - **MLlib**: Biblioteca de aprendizado de máquina.
  - **GraphX**: API para processamento de gráficos.

#### Kafka
- **Conceito**: Plataforma de streaming distribuída que permite a publicação, subscrição, armazenamento e processamento de fluxos de registros em tempo real.
- **Componentes Principais**:
  - **Producer**: Publica mensagens no Kafka.
  - **Consumer**: Lê mensagens do Kafka.
  - **Broker**: Servidor Kafka que armazena dados e serve clientes.
  - **Topic**: Categoria ou feed onde os registros são publicados.
  - **Partition**: Subdivisão de um tópico que permite paralelismo.
  - **Zookeeper**: Coordena e gerencia o cluster Kafka.

### Aspectos Essenciais
- **Escalabilidade**: Todos os três sistemas são projetados para escalar horizontalmente, adicionando mais máquinas ao cluster.
- **Tolerância a Falhas**: Implementam mecanismos para garantir a continuidade do processamento mesmo em caso de falhas de hardware.
- **Processamento em Tempo Real**: Spark e Kafka são especialmente conhecidos por suas capacidades de processamento em tempo real.
- **Integração**: Esses sistemas frequentemente são usados em conjunto para criar pipelines de dados robustos e eficientes.

### Principais Pontos
- **Hadoop**: Ideal para armazenamento e processamento de grandes volumes de dados históricos.
- **Spark**: Focado em processamento rápido e eficiente, tanto em batch quanto em tempo real.
- **Kafka**: Especializado em streaming de dados e integração de sistemas em tempo real.
